> **探测器亦为一层，其「坍缩」只是把自身频率强加于被测层。**

### 公理 B · 漏帧非耗散

漏帧不是从显域移出，是层间失配。定义

```

```

则守恒式取**无减号**形式（v3.0 的字面矛盾由此消解）：

```
P + W + E = Σ₀ ≡ ∫ Σ dV
```

而任一单帧账面读数满足不等式：

```
(P+W+E)|读数 = Σ_k w(Δn_ik)·Σ_k  ≤  Σ₀ ,   Δ_失配 ≥ 0
```

**定理 · 账实一致**：`Δ_失配` 是**观测层的属性**，`Σ₀` 对全体层恒定。
所以「暗」不是本体缺失，是读数失配。

视界不是空间边界，是**「当下张开率」`U ∝ (1 − Σ/Σ*)^(α−1)` 的零点面**。
