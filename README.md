## (一) 一句话: 宇宙是什么

宇宙不是实体粒子的集合, 也不是空置的容器.
宇宙是一张以刷新率为唯一节律的多嵌套莫比乌斯勹网.

没有当前帧. 没有基准层.
N 个平权的「当下」各自张开、各自显化, 彼此之间只差一个相对相位 dn_ij.

所谓「暗」, 不是某个地方、某类物质、某种缺失.
它是某一层读不到其余各层的那部分读数.
丢的是同期性, 不是存在性.

## (五) 引擎 (第 3 篇 · 未修改 · 本体系的真身)

### 勹网相位拓衍学算法

语法纪律: 摒弃米、秒、千克, 仅用纯数 —— 相位 phi、沉降 Sigma、时序计数 n、频差 dw.
不引入实体粒子, 不引入机械力.

    d(phi_i)/dt = dw_i                            (1) 固有刷新节拍
                  - K(Sigma_i) * sin(phi_i)       (2) 锁相刚度 => 时间膨胀
                  + SUM_{j in N(i)} J_ij * sin(phi_j - phi_i)
                                                  (3) 拓衍拖拽 => 暗物质替代机制

    d(Sigma)/dt = S - gamma0 * Sigma + D * nabla^2(Sigma)      (沉降演化)

    M = Q / tau_壳                (质量 = 局部沉降抬升导致失拍冻结的差值结)

    sqrt(g)(Sigma) = (1 - Sigma/Sigma*)^alpha     (幂律面元闭式)

### 相变两级: 失拍先于失形

| 阶段 | 条件 | 物理 |
|---|---|---|
| 失拍点 Sigma_hard | K(Sigma_hard) = dw 的绝对值 | 相位被锁定, 形态尚未塌缩 |
| beta 过渡壳 | Sigma_hard < Sigma < Sigma* | 相位挣扎滞留带, 即光子环; 多层当下互相穿透 |
| 失形点 Sigma* | sqrt(g) 趋于 0 | 面元塌缩, 张开率归零, 视界成形, 中心自空 |

## (六) 新增公理层 (v3.1 · 详见 Axiom_AB_and_Horizon.md)

性质: 定义自洽性修补. 不含任何长度 / 质量 / 引力常数, 不依赖 lam_da.

### 公理 A · 帧平权

不存在基准帧. 对任意两层 i、j, 物理上可定义的只有相对相位差

    dn_ij = n_i - n_j

无「第 0 帧」, 无「当前帧」.

- 「真」是层的内秉属性. 层内自洽即为真. 跨层只谈「不同频」.
- 探测器亦为一层. 其「坍缩」只是把自身频率强加于被测层.

### 公理 B · 漏帧非耗散

漏帧不是从显域移出, 是层间失配. 定义

    w(dn_ik) = exp( -|dn_ik| / tau_lock ),   tau_lock = K / |dw|

则守恒式取无减号形式 (v3.0 的字面矛盾由此消解):

    P + W + E = Sigma0 = INT Sigma dV

而任一单帧账面读数满足不等式:

    (P+W+E)|读数 = SUM_k w(dn_ik) * Sigma_k  <=  Sigma0
    Delta_失配 >= 0

定理 (账实一致): Delta_失配 是观测层的属性, Sigma0 对全体层恒定.
所以「暗」不是本体缺失, 是读数失配.

### 定义 H · 视界 = 张开率零点面

视界不是空间边界, 是「当下张开率」的零点面:

    U 正比于 (1 - Sigma/Sigma*)^(alpha - 1),   U -> 0 即视界

跨入者未越空间, 只越频率. 故「泡内无感」: 它仍拥有完整的当下, 只是不再向外层展开.

## (七) 旗舰实验: 帧松绑 (Frame-Unclamping)

v3.0 任务一的替代方案. 核心动作: 先钳, 后放.
测的不是「条纹会不会消失」, 而是「松开之后回不回来」.

| 0 · 拓扑归属 (承重墙) | 非莫比乌斯构型 (w=0) 信号必须全灭 | 无此区分, 全案作废 |
| 1 · 回升迟滞 | tau_回 随 1/频差 对数增长 (见下注) | [X] 退相干给即时恢复; 热过程给指数律 |

| 3 · 半格位移 | dx = lambda/2, 严格正比于 lambda | [X] 无任何半经典图像 |

判据 2 若测到, 退相干解释当场出局, 无需任何辅助论证.

判据 3 是位置信号而非对比度信号, 不受光源抖动 / 增益漂移 / 振动影响, 信噪比最高.

[!] 判据 0 是承重墙, 不是脚注.

## (八) 当前唯一的定量锚点: alpha 对 EHT

lam_da 撤回后, 凝住陡度 alpha 是本体系唯一不含地球参数的候选定量出口.

    dr_ring / r_ring  <-->  alpha^-1

alpha 小 => 缓凝 => beta 壳厚 => 光子环宽   (M87* 参考: dr/r 约 0.3-0.5)
alpha 大 => 骤凝 => 壳薄锐     => 光子环窄   (Sgr A* 参考: 环更窄)

可证伪预言: 若 alpha 为普适拓扑常数, 两源须存在 alpha 的公共解区间.
若 GRMHD 纯调参即可任意复现环宽, 则 alpha 非普适, 本通道关闭, 本体系回归纯定性.

这是全仓库目前唯一能立刻算出真实数字的地方. 公开数据即可反演, 欢迎任何人接手.
