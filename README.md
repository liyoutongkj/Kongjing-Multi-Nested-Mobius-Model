没有当前帧。没有基准层。
N 个平权的「当下」各自张开、各自显化，彼此之间只差一个相对相位 Delta n_ij。

它是某一层读不到其余各层的那部分读数。
**丢的是同期性，不是存在性。**

> 本节措辞与 `Cosmic_Ontology.md` 严格一致。那是唯一正本，本节为首页摘录。

### 2.1 本体是带厚度的囊式闭环，不是纸带

宇宙本体，是**带厚度的囊式莫比乌斯闭环**，不是教科书那条单薄的莫比乌斯纸带。

莫比乌斯面的性质：只有一个面、一条边界。沿曲面走一周回到起点时已处在对侧，走满两周才真正闭合。
**没有「里面」和「外面」两间房，只有一张连续曲面的两种读法。**

### 2.2 双嵌套 = 本体仅有的两层客观结构

| 层 | 名称 | 内容 |
|---|---|---|
| 第一层 | **囊体表皮（显域层）** | 双层贴合的皮囊。表皮之上析出差值势态，生成玫瑰金宇宙星网、物质、星光——即我们能观测的显域世界 |
| 第二层 | **囊内夹层流体（暗域 · 竟元基底）** | 两层皮囊中间充盈竟元流体，宇宙的潜势基底，对应暗域 |

> **心智类比：压扁的长条水气球。**
> 气球皮 = 囊体表皮；皮中间包的水 = 竟元暗域流体。

### 2.3 视界锁点（涡旋扭结）

双层囊体完成莫比乌斯扭转、首尾闭合后，存在**一处视界锁点**。
此处皮囊发生连续翻卷挤压：

- **几何效果**：外层包裹内层；经拓扑翻转后，内层反过来包裹外层。宇宙原本的实体边界**没有消失**，而是被收纳进这个扭结折痕之内。
- **观测效果**：身在囊体夹层内部看，锁点就是**黑洞**；站在闭环外部高维俯瞰，锁点就是**宇宙的拓扑边界**。

### 2.4 四重嵌套是读法，双嵌套才是本体

「观测嵌套 / 时间嵌套 / 空间（路径）嵌套 / 尺度嵌套」——**四嵌套不是四个独立实体环，不是宇宙的客观分层**。
它是观察者切割**同一个**双嵌套曲面，在四个正交截面上读到的四类现象。

| 嵌套 | 读出内容 | 本质 |
|---|---|---|
| 观测（离子极化环） | 自观 / 相锚 | 双层曲面局部极化，观测侧表达，不独立存在 |
| 时间（波峰扩散环） | 时序折返、流速差异 | 沿闭环单向读出，无时间实体层 |

| 尺度（层级收纳环） | 大 / 小 / 质量 | 皮囊拉伸与挤压的形变效应，无尺度维度实体 |

**坍缩回归**：剥除观测带来的现象外衣之后，客观本体只剩两样——
**囊体表皮（显域） + 夹层竟元流体（暗域）**，经莫比乌斯扭结互相咬合。这就是双嵌套。

## (五) 引擎（第 3 篇 · 未修改 · 本体系的真身）

### 勹网相位拓衍学算法

**语法纪律**：摒弃米、秒、千克，仅用纯数 —— 相位 phi、沉降 Sigma、时序计数 n、频差 Delta omega。不引入实体粒子，不引入机械力。

```
d(phi_i)/dt = Delta_omega_i              (1) 固有刷新节拍
            - K(Sigma_i) * sin(phi_i)    (2) 锁相刚度 => 时间膨胀
            + Sum_{j in N(i)} J_ij * sin(phi_j - phi_i)
                                         (3) 拓扑拖拽 => 暗物质替代机制

d(Sigma)/dt = S - gamma_0 * Sigma + D * grad^2(Sigma)     沉降演化

M = Q / tau_壳         质量 = 局部沉降抬升导致失拍冻结的差值结

sqrt(g)(Sigma) = (1 - Sigma/Sigma*)^alpha                  幂律面元闭式
```

### 相变两级：失拍先于失形

| 阶段 | 条件 | 物理 |
|---|---|---|
| 失拍点 Sigma_hard | 锁相刚度 K 降至与频差绝对值相当 | 相位锁死，**形态未塌，自身无感** |
| beta 过渡壳 | Sigma_hard < Sigma < Sigma* | 相位挣扎滞留带，即光子环；多层当下互相穿透 |
| 失形点 Sigma* | sqrt(g) 趋于 0 | 面元塌缩，张开率归零，视界成形，**中心自空** |

> 注：失拍点的完整条件为 K(Sigma_hard) = |Delta omega|。
> 该式含绝对值符号，放于表外以免表格被竖线劈开。

## (六) 公理层（v3.1 · 详见 `Axiom_AB_and_Horizon.md`）

**性质**：定义自洽性修补，不含任何长度 / 质量 / 引力常数，不依赖 lambda_答。

### 公理 A · 帧平权

不存在基准帧。对任意两层 i、j，物理上可定义的只有相对相位差 Delta n_ij = n_i - n_j。
**无「第 0 帧」，无「当前帧」。**

「真」是层的内秉属性；层内自洽即为真；跨层只谈「不同频」。
探测器亦为一层，其「坍缩」只是把自身频率强加于被测层。

### 公理 B · 漏帧非耗散

漏帧不是从显域移出，是层间失配。定义

```
w(Delta n_ik) = exp( -|Delta n_ik| / tau_锁 ) ,   tau_锁 = K / |Delta omega|
```

则守恒式取**无减号**形式（v3.0 的字面矛盾由此消解）：

```
P + W + E = Sigma_0 = Integral(Sigma dV)
```

而任一单帧账面读数满足不等式：

```
(P + W + E)|读数 = Sum_k w(Delta n_ik) * Sigma_k <= Sigma_0 ,   Delta_失配 >= 0
```

**定理 · 账实一致**：Delta_失配 是观测层的属性，Sigma_0 对全体层恒定。
所以**「暗」不是本体缺失，是读数失配**。

### 定义 H · 视界 = 张开率零点面

视界不是空间边界，是「当下张开率」U 正比于 (1 - Sigma/Sigma*)^(alpha - 1) 的**零点面**。
跨入者未越空间，只越频率——故「泡内无感」：它仍拥有完整的当下，只是不再向外层展开。

```
Delta r_ring / r_ring  <-->  alpha^-1
```
