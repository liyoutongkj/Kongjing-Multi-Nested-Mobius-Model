## (五) 新增公理层（v3.1 · 详见 `Axiom_AB_and_Horizon.md`）

> **性质**：定义自洽性修补，**不含任何长度 / 质量 / 引力常数，不依赖 λ_答**。

**公理 A · 帧平权**
不存在基准帧。对任意两层 i、j，物理上可定义的只有相对相位差
Δn_ij = n_i - n_j。无「第 0 帧」，无「当前帧」。

- 「真」是层的**内秉属性**；层内自洽即为真；跨层只谈「不同频」。
- 探测器亦为一层，其「坍缩」只是把自身频率强加于被测层。

**公理 B · 漏帧非耗散**
漏帧不是从显域移出，是**层间失配**。定义

```
w(Δn_ik) = exp( -|Δn_ik| / τ_锁 ) ，  τ_锁 = K / |Δω|
```

则守恒式取**无减号**形式（v3.0 的字面矛盾由此消解）：

```
P + W + E = Σ0 ≡ ∫ Σ dV
```

而任一单帧账面读数满足不等式：

```
(P+W+E)|读数 = Σ_k w(Δn_ik)·Σ_k  ≤  Σ0 ，  Δ_失配 ≥ 0
```

**定理 · 账实一致**：Δ_失配 是**观测层的属性**，Σ0 对全体层恒定。
所以「暗」不是本体缺失，是**读数失配**。

**定义 H · 视界 = 张开率零点面**
视界不是空间边界，是「当下张开率」U 正比于 (1 - Σ/Σ*)^(α-1) 的**零点面**。
跨入者**未越空间，只越频率** —— 故「泡内无感」：它仍拥有完整的当下，只是不再向外层展开。
